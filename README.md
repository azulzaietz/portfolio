# Portfolio - Azul Zaietz

Makeup artist portfolio website, designed for GitHub Pages.

## Features
- Horizontal banner header photo at the top.
- Grid gallery of high-resolution portrait makeup works.
- Fully responsive layout with local optimized WebP assets.
- Ready for GitHub Pages deployment.

## Running Locally
You can view the site locally by opening `index.html` in any browser or serving it:
```bash
python3 -m http.server 8000
```
